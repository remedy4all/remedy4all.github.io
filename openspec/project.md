# Project Context

The project's architecture, conventions, glossary, toolchain commands and security expectations
are kept in one place, **`.claude/project.md`**, so they cannot drift. Read it before writing a
proposal.

## Purpose
Public, static, bilingual (Greek primary, English second) website of ΑΜΚΕ «REMEDY FOR ALL».

## Tech Stack
- Astro (static output), npm, TypeScript strict
- GitHub Actions to GitHub Pages

## Important Constraints
- Facts about the organisation come only from its statute or from a request; nothing is invented.
- No personal data from the statute, anywhere.
- No third-party scripts, trackers, cookies or CDN fonts.
- No push and no remote without his instruction.
